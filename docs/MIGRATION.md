# Migration onto Client3

Base: `lesleyrs/Client3` commit `53c4cf8dbc20cedf588ee07684709f3cd3aee2b7`, which is also `me11yb3an/Client3` `main`. Compared on 2 November 2026. Newline differences alone were not treated as changes. Upstream blobs were left in place for those files.

Counts below are the `src-tree/` export against `src/` in Client3.

| Result | Count | What was done |
| --- | ---: | --- |
| Text matches Client3 | 91 | Left as the Client3 blob |
| Content differs | 66 | Replaced with the export blob |
| No Client3 path | 178 | Added under `src/` |

Of the 91 matches, 16 are under `thirdparty/` and 75 are application files. Of the 66 overlays, 7 are under `thirdparty/` (`bzip.c`, `rsa-bigint.c`, `rsa-libtom.c`, `rsa-openssl.c`, `rsa-tiny.c`, `rsa.h`, `tsf.h`) and 59 are application files.

Files copied beside `src/` and not part of those three counts: `src/embedded_server.c`, `src/world_worker.h`, `src/r103_save_native_read.h`, `src/r64_banker_defaults.h`, `g17_cache_io.c`, `packet_queue.h`, `save/`, `server/`, `docs/`, `provenance/src-tree.rar`, and `SOURCE-MANIFEST.json`. `src/offline_vita.c` is the export file `units.mk` compiles. The other `offline_vita.c` from the archive is `provenance/src-tree-offline_vita.c`.

No `.vpk`, `.pak`, `.suprx`, or `.sav` was added. Client3 `rom/` was already in the base commit and was not modified.
